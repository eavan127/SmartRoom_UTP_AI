# Collected UTP photos (drop folder)

Put **all** photos downloaded from the Google Forms Drive folder here, as they are, in one flat folder.
No renaming or sorting needed.

Google Forms names each upload `<original name> - <respondent name>.<ext>`, so files whose names
share the same respondent part belong to the same person. A script (to be added) will group them,
number them `001, 002, ...` after checking which file is the student ID photo, and write the same
layout as `open_lfw/` (`001/001_1.jpg` = ID photo, `001/001_2.jpg` = normal photo).

Only include respondents who gave consent. Never commit these files.
